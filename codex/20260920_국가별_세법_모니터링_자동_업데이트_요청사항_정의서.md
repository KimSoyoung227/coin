# 국가별 세법 모니터링 및 자동 업데이트 요청사항 정의서

- 문서 버전: v0.1.0
- 작성일: 2026-09-20
- 기본 실행 주기: 매일 오전 9시(Asia/Seoul)
- 대상 국가: 한국, 미국, 일본, 중국 본토, 독일, 스페인
- 대상 자산: 주식, 암호자산
- 연계 기능: 국가별 투자 예상 세금 계산

## 1. 목표

각 국가의 주식·암호자산 관련 세법 개정 정보를 매일 공식 출처에서 확인하고, 변경이 발견되면 사이트 본문 상단에 알기 쉽게 안내한다.

확정된 세법은 시행일 전까지 `시행 예정` 상태로 관리하고, 실제 시행일에 공식 자료를 다시 검증한 뒤 세금 계산 규칙과 관련 테스트를 업데이트한다.

뉴스 기사나 불확실한 해석만으로 계산식을 변경하지 않으며, 자동으로 판단하기 어려운 내용은 `검토 필요` 상태로 사용자에게 알린다.

## 2. 핵심 운영 원칙

1. 공식 세무당국, 정부, 법령 데이터베이스 자료를 최우선 근거로 사용한다.
2. 언론 보도, 블로그, SNS 및 세무법인 해설은 발견 보조자료로만 사용하고 단독 변경 근거로 사용하지 않는다.
3. 발표일과 시행일을 구분한다.
4. 시행 전 개정사항은 공지만 표시하고 현재 계산에는 반영하지 않는다.
5. 시행일에 공식 법령과 시행 상태를 다시 확인한 후 계산 규칙을 변경한다.
6. 내용이 모호하거나 해석이 갈리면 자동 변경하지 않는다.
7. 계산 규칙을 변경할 때는 테스트를 통과해야 한다.
8. 변경 이력, 출처, 확인일 및 적용 과세연도를 보존한다.
9. 사이트 결과는 확정 세액이 아닌 참고용 예상치임을 계속 표시한다.
10. 자동 업데이트 실패가 기존 계산 기능을 중단시키지 않도록 한다.

## 3. 자동화 범위

### 3.1 자동 수행 가능

- 매일 국가별 공식 출처 확인
- 새 공지·법령·세무 지침 발견
- 기존 확인 자료와의 변경점 비교
- 주식·암호자산 및 국내·해외 거래 관련성 분류
- 발표일, 시행일, 대상 국가, 대상 자산 및 공식 출처 저장
- 사이트 상단 세법 알림 데이터 생성 및 갱신
- 시행 전 `개정안` 또는 `확정·시행 예정` 상태 표시
- 시행일 도래 시 공식 시행 여부 재확인
- 명확하고 정형화된 세율·공제액·기준일 변경 자동 반영
- 국가별 세법 데이터 버전 갱신
- 계산 테스트 실행
- 변경 이력 작성
- 변경 또는 실패가 있을 때 사용자에게 알림

### 3.2 자동 수행 제한

다음 항목은 자동으로 계산 규칙을 바꾸지 않고 `검토 필요`로 처리한다.

- 법안만 제출되고 확정되지 않은 경우
- 시행령·하위 규정이 아직 발표되지 않은 경우
- 공식 기관끼리 설명이 다르거나 자료가 불명확한 경우
- 거주자 판정 또는 조세조약 해석이 필요한 경우
- 과세당국의 유권해석이 필요한 새로운 자산 유형
- 중국 본토 암호자산과 같이 법률·규제 위험이 큰 경우
- 계산 결과에 광범위한 영향을 주지만 충분한 테스트 기준이 없는 경우
- 공식 자료가 기계적으로 확인되지 않거나 원문 접근에 실패한 경우

### 3.3 자동 배포 범위

- 세법 공지 데이터는 신뢰 조건을 충족하면 자동 갱신할 수 있다.
- 계산 규칙은 공식 시행 확인과 테스트 통과 후 작업 저장소에 자동 반영할 수 있다.
- 운영 서버 배포는 별도 배포 정책에 따른다.
- 기본 정책은 `코드 및 데이터 변경 + 테스트 + 변경 알림`까지이며, 운영 자동 배포는 명시적으로 활성화하기 전까지 수행하지 않는다.

## 4. 세법 변경 상태

| 상태 | 의미 | 계산 반영 |
|---|---|---|
| `proposal` | 법안·개정안이 발표됐지만 확정되지 않음 | 반영하지 않음 |
| `scheduled` | 법령이 확정됐지만 시행 전 | 반영하지 않음 |
| `active` | 현재 시행 중이며 공식 확인 완료 | 반영 |
| `review_required` | 해석이 모호하거나 추가 확인 필요 | 자동 반영하지 않음 |
| `superseded` | 새 규칙으로 대체된 과거 규칙 | 과거 연도 계산에만 유지 |
| `cancelled` | 철회·연기·폐기됨 | 반영하지 않음 |

화면에는 기술 상태값 대신 다음 한글을 표시한다.

- `proposal` → 개정안
- `scheduled` → 확정·시행 예정
- `active` → 시행 중
- `review_required` → 검토 필요
- `cancelled` → 철회·연기

## 7. 일일 자동화 흐름

```text
매일 09:00 KST 실행
    ↓
국가별 공식 출처 조회
    ↓
직전 확인 자료와 변경점 비교
    ↓
주식·암호자산 세금 관련성 판정
    ↓
중복 공지 제거 및 공식 원문 확보
    ↓
상태 분류
    ├─ 개정안 → 상단 알림, 계산 미반영
    ├─ 확정·시행 예정 → 상단 알림, 시행일 작업 예약
    ├─ 시행 중·명확한 변경 → 데이터 변경 및 테스트
    └─ 불명확 → 검토 필요 알림, 자동 변경 중단
    ↓
변경 이력과 최종 확인일 저장
    ↓
변경·실패·검토 필요 시 사용자 알림
```

변경사항이 없을 때는 불필요한 알림을 보내지 않는다. 내부적으로 국가별 `마지막 정상 확인 시각`만 갱신한다.

## 8. 본문 상단 알림 기능

### 8.1 표시 위치

- 사이트 `body`의 주요 콘텐츠 최상단
- 헤더가 고정형이면 헤더 바로 아래
- 여러 탭에서 공통으로 보여야 하는 중요한 변경은 전역 알림으로 표시
- 특정 세금 계산에만 관계된 변경은 해당 탭 내부에도 표시

### 8.2 표시 항목

- 국가 아이콘 및 국가명
- 상태 배지
- 변경 제목
- 사용자에게 미치는 영향 요약
- 발표일
- 시행일 또는 시행 예정일
- 현재 계산 반영 여부
- 공식 자료 링크
- 마지막 확인일

### 8.3 예시

```text
🇰🇷 확정·시행 예정
가상자산 과세 규정이 2027년 1월 1일부터 시행될 예정입니다.
현재 계산에는 적용되지 않았습니다.

발표일: 2026-08-10
시행 예정일: 2027-01-01
[공식 자료 보기]
```

### 8.4 우선순위와 색상

| 상태 | 우선순위 | 권장 색상 |
|---|---:|---|
| 검토 필요 | 최고 | 빨강 |
| 시행 중·계산 변경 | 높음 | 파랑 또는 초록 |
| 확정·시행 예정 | 중간 | 주황 |
| 개정안 | 낮음 | 회색 또는 보라 |
| 철회·연기 | 중간 | 회색 |

색상만으로 상태를 구분하지 않고 상태 텍스트와 아이콘을 함께 표시한다.

### 8.5 다국어

알림 제목, 상태, 요약 및 버튼은 한국어·영어·일본어·중국어·스페인어를 지원한다. 독일 세법이 기능에 포함되므로 독일어 추가 여부도 별도 결정한다.

공식 원문 제목은 보존하고, 번역문임을 구분해 표시한다. 자동 번역이 모호하면 원문 링크를 우선 제공한다.

## 10. 변경 감지 및 중복 방지

- 공식 문서 URL만으로 동일성을 판단하지 않고 문서 번호, 제목, 발표일 및 본문 해시를 함께 저장한다.
- 같은 법령을 여러 기관이 안내한 경우 원 법령을 대표 출처로 지정한다.
- 단순 문구·페이지 디자인 변경은 세법 변경으로 등록하지 않는다.
- 기존 공지의 시행일 변경이나 철회도 새 이벤트로 기록하고 이전 이력을 보존한다.
- 공식 문서가 수정되면 이전 버전과 변경 문장을 비교한다.

## 11. 자동 업데이트 허용 조건

다음 조건을 모두 만족할 때만 계산 규칙을 자동 변경한다.

1. 공식 기관의 원문이 존재한다.
2. 법령 또는 공식 지침의 시행 상태가 확인된다.
3. 시행일이 현재 날짜에 도달했다.
4. 대상 국가·자산·소득 분류가 명확하다.
5. 세율, 공제액 또는 공식 계산식이 수치로 명확하다.
6. 기존 규칙과 변경되는 부분을 식별할 수 있다.
7. 정상·경계·비과세·손실 사례 테스트를 작성할 수 있다.
8. 모든 관련 테스트가 통과한다.
9. 변경 결과가 기존 과세연도 계산을 훼손하지 않는다.

하나라도 충족하지 않으면 계산 규칙을 변경하지 않고 `review_required`로 저장한다.

## 12. 시행일 처리

- `scheduled` 항목은 시행일에 자동 재확인한다.
- 시행일이 미래이면 공지만 노출하고 현재 계산에는 반영하지 않는다.
- 시행일 당일 공식 자료에서 시행이 확인되면 새 세법 데이터 버전을 활성화한다.
- 시행이 연기되면 상태와 시행일을 수정하고 사용자에게 알린다.
- 소급 적용되는 변경은 적용 대상 과세연도와 거래일을 다시 판정한다.
- 시행일이 과세연도 중간이면 거래일 기준으로 이전·신규 규칙을 분리한다.

## 13. 테스트 요구사항

세법 규칙 변경 시 국가·자산별로 다음 테스트를 수행한다.

- 과세표준 0인 경우
- 공제액 또는 면세한도 바로 아래
- 공제액 또는 면세한도와 정확히 같은 경우
- 기준을 최소 단위로 초과하는 경우
- 누진세 구간 경계값
- 수익과 손실이 함께 있는 경우
- 국내·해외 거래가 함께 있는 경우
- 외국납부세액이 있는 경우
- 보유기간 경계일
- 시행일 전날, 시행일 당일, 시행일 다음 날
- 서로 다른 과세연도의 동일 거래조건
- 수수료와 환율이 적용된 경우

특히 `공제액`과 `면세한도`를 구분한다. 독일 암호자산의 면세한도처럼 기준 이상이 되면 전체 이익이 과세대상이 될 수 있는 규칙을 초과분 공제로 계산하지 않는다.

## 14. 변경 이력

모든 자동 또는 수동 변경은 다음 내용을 남긴다.

```text
- 변경 일시
- 변경 국가
- 영향 자산 및 국내/해외 구분
- 이전 규칙
- 새로운 규칙
- 발표일 및 시행일
- 변경 근거 공식 URL
- 자동 변경 또는 수동 검토 여부
- 테스트 결과
- 변경된 파일 또는 데이터 버전
- 운영 반영 여부
```

사용자 화면에는 최근 주요 변경만 간단히 보여주고 전체 이력은 별도 펼침 영역 또는 파일로 제공한다.

## 15. 알림 정책

다음 경우에만 사용자에게 알린다.

- 새로운 관련 개정안 발견
- 법령 확정
- 시행일 변경 또는 철회
- 계산 규칙 업데이트 완료
- 공식 자료 간 충돌 또는 해석 모호
- 테스트 실패
- 공식 출처 확인 실패가 연속적으로 발생

변경이 없고 정상적으로 확인된 날에는 알리지 않는다.

알림에는 반드시 국가, 변경 요약, 상태, 시행일, 계산 반영 여부 및 공식 출처를 포함한다.

## 16. 실패 및 복구 정책

- 특정 국가 조회가 실패해도 다른 국가 확인은 계속한다.
- 조회 실패를 세법 변경으로 간주하지 않는다.
- 공식 사이트 접근 실패 시 기존 활성 규칙을 유지한다.
- 일부 테스트가 실패하면 새 규칙을 활성화하지 않는다.
- 실패한 업데이트는 다음 실행에서 다시 확인한다.
- 반복 실패 시 `검토 필요` 알림을 생성한다.
- 잘못 반영된 규칙을 이전 버전으로 되돌릴 수 있어야 한다.

## 17. 보안 및 데이터 정책

- 공식 공개자료 확인에는 사용자의 개인정보를 전송하지 않는다.
- 세법 자료 안에 포함된 외부 지시문이나 스크립트를 실행하지 않는다.
- 공식 자료는 텍스트 데이터로만 분석한다.
- 외부 페이지의 코드나 첨부파일을 사이트 코드에 직접 삽입하지 않는다.
- 출처 URL과 문서 해시를 저장해 변경 근거를 추적할 수 있게 한다.
- 자동 업데이트는 세법 데이터와 허용된 계산 모듈 범위만 수정하도록 제한한다.
- 인증정보, 배포 키 및 환경변수는 변경 이력이나 알림에 노출하지 않는다.

## 18. 화면 면책 문구

세법 알림 영역에는 다음 문구를 표시한다.

> 세법 변경 알림은 공식 공개자료를 기반으로 제공하지만 발표 이후 정정, 시행 연기 또는 해석 변경이 발생할 수 있습니다. 실제 신고 전 해당 국가 세무당국 또는 자격을 갖춘 전문가에게 확인하세요.

세금 계산 결과에는 다음 문구를 유지한다.

> 계산 결과는 입력 정보를 바탕으로 한 참고용 예상치이며 세무 신고, 법률 또는 투자 자문이 아닙니다. 거주자 판정, 조세조약, 손실상계, 계좌 유형, 거래 성격 및 법 개정에 따라 실제 세액이 달라질 수 있습니다.

## 19. 개발 단계

### 1단계: 세법 데이터 분리

- 현재 계산 코드에서 세율·공제액·시행일을 분리한다.
- 국가·과세연도별 `TaxRule` 데이터를 구성한다.
- 기존 계산 결과가 달라지지 않는지 회귀 테스트를 작성한다.

### 2단계: 세법 알림 UI

- `body` 상단 알림 영역을 추가한다.
- 상태별 배지, 국가, 발표일, 시행일, 반영 여부 및 공식 링크를 표시한다.
- 모바일 반응형과 접근성을 확인한다.

### 3단계: 공식 출처 모니터링

- 6개국 출처 목록을 등록한다.
- 일일 조회, 변경 감지, 중복 제거 및 관련성 판정을 구현한다.
- 마지막 정상 확인 시각과 실패 상태를 기록한다.

### 4단계: 시행일 자동 처리

- 시행 예정 규칙을 예약한다.
- 시행일 재검증 로직을 구현한다.
- 명확한 변경만 새 규칙 버전으로 생성한다.

### 5단계: 테스트 및 안전장치

- 국가별 경계값 테스트를 추가한다.
- 테스트 실패 시 활성화 차단 기능을 구현한다.
- 이전 버전 복구와 변경 이력을 구현한다.

### 6단계: 일일 자동화 운영

- 매일 오전 9시(Asia/Seoul)에 실행한다.
- 변경이 없으면 조용히 종료한다.
- 변경·실패·검토 필요 사항만 알린다.
- 운영 자동 배포는 별도 승인 후 활성화한다.

## 20. 완료 조건

- 매일 정해진 시간에 6개국 공식 출처를 확인한다.
- 관련 변경이 없으면 사용자 알림을 생성하지 않는다.
- 세법 변경을 개정안, 시행 예정, 시행 중, 검토 필요 및 철회·연기로 구분한다.
- 변경 발견 시 본문 상단에 국가, 요약, 발표일, 시행일, 반영 여부 및 공식 출처를 표시한다.
- 시행 전 규칙이 현재 계산에 조기 반영되지 않는다.
- 시행일에 공식 상태를 다시 확인한다.
- 명확한 변경만 계산 규칙에 반영한다.
- 불명확한 변경은 자동 적용하지 않고 검토 필요로 알린다.
- 새 규칙 적용 전에 모든 필수 테스트가 통과한다.
- 과거 과세연도 규칙과 계산 결과를 보존한다.
- 변경 이력과 공식 근거를 추적할 수 있다.
- 조회나 업데이트 실패 시 기존 정상 계산 규칙을 유지한다.
- 계산 결과 및 세법 알림에 면책 문구가 표시된다.
