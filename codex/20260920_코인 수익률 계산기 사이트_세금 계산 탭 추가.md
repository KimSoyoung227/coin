[목표] 나라별(한국, 미국, 일본, 중국, 독일, 스페인) 주식/코인별 국내/해외 거래에 대한 예상 세액을 계산해주는 '세금 계산' 탭을 추가하고자 해.

[기능]
- 외국인들도 한국에서 거래할 수 있으니까 url 컨텍스트 패스에 따라 세금법을 고정하지 **않고**, 세금 계산 탭 안에서 세법상 거주 국가를 선택할 수 있는 select box에서 선택할 수 있도록 할거야. 
- 그리고 계산 기능의 세부 내용은 './20260920_주식_코인_국가별_세금_계산_요청사항_정의서.md' 를 참고하도록 해. 설명란은 추가하는데 꼭 주의해야할 부분에는 스타일 강조를 해줘.
- 최신 세법인지를 알려줘야 하니까 세법을 찾아본 기준 일자를 보여줬으면 좋겠어.
- 디자인은 select box, checkbox, text, radio, toggle 등의 태그들을 잘 활용하도록 해.
- 반응형 디자인을 할 때, 웬만해서는 입력값이 화면 안에 다 들어와 있으면 좋겠어. 하지만 입력값이 많아서 안된다면 어쩔 수 없지.
- PC에서 입력 label을 마우스 오버하거나 MO에서 입력label을 꾹 누르면 입력항목에 대한 설명도 있으면 좋겠다. 아니면 text에 placeholder로 보여주거나.
- 결과를 보여주는 영역에는 결과뿐만이 아니라 계산법까지 알려줘. 그러면 사용자들이 신뢰하거나 오류를 잘 파악할 수 있을것 같아.
- 각 스타일은 기존의 사이트 스타일에 조화롭게 해줘.

[개발]
- 개발언어는 python이다. 사이트를 만들기 위해 필요한 패키지만 설치한다.
- 디비가 필요한 경우인지 검토해서 디비가 필요하면 나에게 보고한다.
- 각각의 모듈을 개발하고 나서 나에게 검토 확인을 요청한다.
- 토큰은 최소한으로 사용하게 한다.
- 나에게 답변은 최소한으로 한다. 코드를 나에게 알려주지 않고 코드 인덱스를 알려주거나 폴더 경로를 알려준다.

[추가]
- 너가 만든 화면을 보니까 취득내역 tax-trades 안에 취득 내역 tax-lots와 처분내역 tax-grid로 감싸져있는데, 취득 내역 안에는 취득 내역만 있었으면 좋겠어. 2개의 레이아웃을 분리해줘.
- 취득 내역 레이아웃 안에 '삭제', '취득 내역 추가' 버튼 디자인도 기존 사이트 스타일에 맞춰서 바꿔줘.
- 현재의 '총액에 수수료 반영됨' 체크박스는 어떤 입력항목과 상관이 있는거야? 관련된 입력항목 tax-field 영역 내에 조그맣게 들어갔으면 좋겠어. 그리고 이건 궁금한건데 수수료가 직접 수수료와 다른 수수료야? 총액에 수수료가 반영되었다고 하더라도 '직접 수수료 (거래통화)'는 별도로 작성해야 하는건지 궁금해. 
- 입력 항목 중에 선택사항이 있는지 확인해주고, 선택사항 입력 항목이 존재하면 필수 입력항목 label 앞에 '*' 표시를 붙여줘.
