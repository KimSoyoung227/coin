[목표] 언어별 페이지를 분리해서 다국어 seo가 개선되었으면 좋겠어.
[기능] 
- 한국어 : https://coin.sykim.dev/ko/, 영어 : https://coin.sykim.dev/en/, 일본어 : https://coin.sykim.dev/ja/, 중국어 : https://coin.sykim.dev/zh/ 스페인 : https://coin.sykim.dev/es/ 페이지 분리한다.
- 기본 coin.sykim.dev의 메인 페이지는 사이트에 접속하는 나라의 언어로 보여주고, 만약 한국, 중국, 일본어, 스페인어, 영어권 나라가 아니면 기본적으로는 영어 url로 메인으로 띄워줘.
- 헤더 상단에 나라 아이콘을 클릭하면 언어별 페이지로 이동하게 수정해줘.
- 버튼에 hreflang 속성을 넣을 수 있다면 좋겠어.

- 각 언어별 페이지의 title과 meta description, h1, 설명문, label까지 서버에서 렌더링을 하고 hreflang, sitemap.xml, canonical까지 설정해줘. 

[개발]
- 개발언어는 python이다. 사이트를 만들기 위해 필요한 패키지만 설치한다.
- 디비가 필요한 경우인지 검토해서 디비가 필요하면 나에게 보고한다.
- 각각의 모듈을 개발하고 나서 나에게 검토 확인을 요청한다.
- 토큰은 최소한으로 사용하게 한다.
- 나에게 답변은 최소한으로 한다. 코드를 나에게 알려주지 않고 코드 인덱스를 알려주거나 폴더 경로를 알려준다.
- 코드 개발하면서 각 함수 또는 모듈에 대한 주석을 적어준다.
- 보안이 필요한 부분은 .gitignore 파일에 넣는다.
- 개발하면서 .md 파일에 너가 했던 작업을 일지로 작성한다.
- 커밋 메시지는 [Mager].[Minor].[Patch]형태의 개발 버전을 기록한다. 현재는 아직 정식 출시하지 않으므로 Mager는 0이다.
