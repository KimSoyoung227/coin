[목표] 환율 조회하는 레이아웃을 추가하고 싶어.
[기능] 
- pc에는 사이드에 mo에는 하단에 환율 조회하는 레이아웃을 추가하고 싶어.
- 환율은 KRW, USD, CNY, JYP, EUR, GBP, 금, 은, 구리, 비트코인이야.
- 환율은 표 또는 슬라이드처럼 한눈에 보였으면 좋겠어.
- 디자인은 간략하고 간소화되었으면 좋겠어.
- 금, 은, 구리는 oz 말고 g으로 계산해서 보여줘.
- 반응형 페이지인 것을 기억해야해.
- BTC는 Gold public API를 이용해서 1분마다 갱신해줘.
- 금, 은, 구리는 Gold public API를 이용해서 5분마다 갱신해줘.
- 화폐 환율은 ExchangeRate.fun의 무료 API를 이용해서 시간단위로 보여줘.
- 각 데이터를 조회 처리 완료된 일시를 사용자들에게 노출해줘. 
- api 출처를 사용자에게 보여줘야해.

[개발]
- 개발언어는 python이다. 사이트를 만들기 위해 필요한 패키지만 설치한다.
- 디비가 필요한 경우인지 검토해서 디비가 필요하면 나에게 보고한다.
- 각각의 모듈을 개발하고 나서 나에게 검토 확인을 요청한다.
- 토큰은 최소한으로 사용하게 한다.
- 나에게 답변은 최소한으로 한다. 코드를 나에게 알려주지 않고 코드 인덱스를 알려주거나 폴더 경로를 알려준다.
- 코드 개발하면서 각 함수 또는 모듈에 대한 주석을 적어준다.
- 보안이 필요한 부분은 .gitignore 파일에 넣는다.
- 개발하면서 .md 파일에 너가 했던 작업을 일지로 작성한다.
- 커밋 메시지는 [Mager].[Minor].[Patch]형태의 개발 버전을 기록한다. 현재는 아직 정식 출시하지 않으므로 Mager는 0이다.
- BTC는 1분 캐시, 금/은/구리는 5분 캐시, 환율은 1시간 캐시로 저장해줘.
